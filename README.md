# Password Analyzer

A command-line password strength analyzer built in C.

The program analyzes a password based on its length, character composition,
theoretical entropy, and simple predictable patterns. It then assigns a
strength level and star rating with ANSI terminal colors.

## Features

- Password length analysis
- Uppercase letter detection
- Lowercase letter detection
- Digit detection
- Special character detection
- Character pool calculation
- Entropy calculation in bits
- Sequential character detection
- Repeated character detection
- Strength classification
- 1–5 star rating
- ANSI-colored terminal output
- 99-character input limit

## How It Works

```text
Password
   ↓
Length Analysis
   ↓
Character Composition
   ↓
Character Pool
   ↓
Entropy Calculation
   ↓
Pattern Detection
   ↓
Strength Classification
   ↓
Final Rating
